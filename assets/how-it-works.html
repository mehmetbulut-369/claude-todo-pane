1You open Claude Code. The plugin opens a pane.
2The pane asks the To Do MCP server on your Mac.a small local program you install once
3The server asks Microsoft, with your own login.the plugin never sees a password or a token
4Your lists come back as text.the plugin turns that text into rows
5Click ○ and the task is completed in To Do itself.
6So your phone sees it too.the pane refreshes on its own every 5 minutes

That's the whole trick.

One pane, one local server, your own Microsoft account.
